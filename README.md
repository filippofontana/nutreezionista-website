# 🌱 Nutrizionista Website

This is a simple Hugo website based on the
[Hugo Scroll](https://github.com/zjedi/hugo-scroll) template.

## Development

The website is made using the [Hugo](https://gohugo.io/) static site generator.
The build and rendering steps are simplified with the `run.sh` script, which
uses a Docker container under the hood, so no dependencies needed.
